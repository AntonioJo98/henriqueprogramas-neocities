# Public game scoreboard

Cloudflare Worker + D1 backend for Snake, Turtle Crossing and Whack-a-Mole.

- Every valid result remains in D1.
- Public GET responses return only the best 20 per game.
- Ties are ordered by the earliest server timestamp.
- `created_at` is generated by D1; browser-supplied dates are ignored.
- No email, account or IP address is stored in the database.
- Player names are public nicknames limited to 2–20 safe characters.

The Worker accepts writes only from `https://henriquemaulaz.neocities.org` and applies a submission rate limit. Browser scores can still be forged by a technically capable visitor, so this is a recreational, not verified-competitive, ranking.
