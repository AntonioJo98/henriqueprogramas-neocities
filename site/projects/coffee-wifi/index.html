About this rebuild

This browser directory revisits the Coffee & WiFi Flask exercise from Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp. The original explored routes, templates, CSV data and forms. This static version recreates the filtering and form interaction with JavaScript, local demo data and localStorage, which works on Neocities without a Python server.
