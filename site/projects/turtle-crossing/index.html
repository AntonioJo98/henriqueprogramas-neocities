About this rebuild

This browser game revisits the Turtle Crossing exercise from Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp. The original lesson used Python Turtle; this is a new JavaScript Canvas implementation with four-direction controls, responsive presentation, and automated tests.
