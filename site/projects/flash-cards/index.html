About this rebuild

This project revisits the Flash Card App exercise from Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp. The original used Python Tkinter, CSV data and a three-second flip. This browser implementation uses locally curated vocabulary, keyboard support and localStorage so progress stays on this device.
