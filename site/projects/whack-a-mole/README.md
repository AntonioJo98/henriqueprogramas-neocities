# Whack-a-Mole — original JavaScript practice project

A short reaction game built as an original complementary portfolio project.

## Features
- Nine keyboard-operable/touch-friendly holes
- 30-second countdown
- Random mole positions
- Score and hit tracking
- Responsive layout and accessible status updates

## Run locally
```bash
python -m http.server 8771 --directory site
node --test tests/mole-engine.test.mjs tests/mole-ui.test.mjs
```
